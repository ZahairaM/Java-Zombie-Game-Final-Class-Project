# Java-Zombie-Game-Final-Class-Project
A 2D game created in Java as my final project for an Object-Oriented Programming course. For this project, I was given a general assignment structure but had the freedom to develop my own game concept and decide how I wanted to implement it.

# About-the-Project
This was one of my first larger programming projects where I had the opportunity to create something based on my own idea rather than following a detailed template. I designed the concept and worked through the game's mechanics and structure using the object-oriented programming concepts I learned throughout the course.

While the game is still an early project and has room for additional polish and improvements, I am proud of what I was able to create with the skills I had at the time. The project gave me experience taking an idea from the planning stage and turning it into a complete, playable program.

# Game-Overview
The game is a simple survival-style game where the player controls a human trying to escape a pursuing zombie. The goal is to collect stars throughout the map, which increase the player's movement speed and help them stay ahead of the zombie.

# How-to-Play
- Click to start the game.
- Use the arrow keys to move the player/human.
- Collect Stars to increase your speed.
- Avoid the zombie as it continues to chase you.
